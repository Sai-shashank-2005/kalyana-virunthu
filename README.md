# Kalyana Virunthu — Wedding Invitation Website

A premium, mobile-first South Indian wedding invitation website for **Santhosh Ananth & Shunmugapriya**.

Featuring a custom scroll-driven parallax hero, warm ivory paper stationery styling, temple-maroon typography, antique-gold details, and subtle traditional animations.
